# More Features — برچسب محصول (Product Labels)

طراحی برچسبِ روی محصول برای **فروشگاه سلیم‌وند**، کاملاً هم‌راستا با زبان بصری
رابط کاربری پروژه (توکن‌های `css_base.css`: ناوی برند `#0d2b4b`، شعاع گوشه، فونت وزیرمتن، چیدمان RTL).

فایل خروجی: **`product-labels.html`** — تک‌فایلی و کاملاً آفلاین (فونت وزیرمتن به‌صورت base64 جاسازی شده،
بارکد با جاوااسکریپت خالص و بدون هیچ کتابخانه یا منبع خارجی رسم می‌شود).

## روی برچسب چه چیزی هست؟

| بخش | محتوا |
|---|---|
| سربرگ ناوی | نشان «س» + **نام فروشگاه: فروشگاه سلیم‌وند** + آدرس سایت **salimvand.ir** |
| بدنه | **نام محصول** (تا ۲ خط)، چیپ دسته‌بندی، خودروهای سازگار، **کد کالا (SKU)** |
| بارکد | **خطوط بارکد + عدد بارکد** زیر آن (EAN-13 یا Code 128) |
| پانویس | «اصالت و گارانتی کالا» + `salimvand.ir` |

## اندازه‌ها

| اندازه | کاربرد |
|---|---|
| **۵۰×۳۰ میلی‌متر** | اندازهٔ پیش‌فرض؛ اکثر قطعات (رول لیبل استاندارد) |
| **۶۰×۴۰ میلی‌متر** | کارتن و قطعات بزرگ (باتری، رادیاتور) |
| **۳۸×۲۲ میلی‌متر** | قطعات کوچک (شمع، فیلتر، سنسور) |

## سبک‌های چاپ

- **برند (رنگی)** — سربرگ ناوی `#0d2b4b` با نوار لهجهٔ آبی `#3f8ede`؛ برای چاپ رنگی.
- **تک‌رنگ** — سیاه‌وسفید خالص، بهینه برای **چاپگر حرارتی لیبل‌زن**.
- **ناوی** — برچسب تمام‌ناوی پریمیوم؛ بارکد داخل کادر سفید (برای اسکن‌پذیری).

## بارکد

- **EAN-13**: از روی SKU به‌صورت پایدار ساخته می‌شود؛ پیشوند `626` (کد کشوری ایران در GS1)
  و **رقم کنترلی خودکار**. مناسب فروش و صندوق.
- **Code 128 (حالت B)**: دقیقاً همان کد داخلی انبار (مثل `BRK-00452`) را کدگذاری می‌کند؛
  مناسب انبارگردانی و اسکن داخلی.
- بارکد به‌صورت **SVG برداری** با `shape-rendering: crispEdges` رسم می‌شود تا در چاپ لبه‌ها تیز بمانند.

## استفاده

```bash
# فقط باز کردن خروجی آماده:
xdg-open product-labels.html

# یا بازسازی از روی قالب (فونت را از ui/selim-vand/fonts_b64.json می‌خواند):
python3 build_labels.py        # → product-labels.html

# تست صحت (۱۷ تست: رقم کنترلی، تعداد ماژول‌ها، اجزای برچسب):
npm i jsdom && node verify_labels.js
```

در صفحه: انتخاب محصول از دادهٔ نمونهٔ انبار، ویرایش زندهٔ همهٔ فیلدها، تعویض اندازه/سبک/نوع بارکد،
بزرگ‌نمایی ۲×/۳×/۴× و دکمهٔ **«چاپ برگهٔ A4»** که برچسب‌ها را در تعداد دلخواه روی A4
(حاشیهٔ ۸ میلی‌متر، فاصلهٔ ۲ میلی‌متر) می‌چیند. اندازه‌ها با واحد `mm` تعریف شده‌اند،
پس خروجی چاپ **دقیقاً در ابعاد واقعی** است — هنگام چاپ گزینهٔ مقیاس را روی ۱۰۰٪ بگذارید.

## نکات چاپ

- کمترین ارتفاع پیشنهادی میله‌ها رعایت شده؛ برای اسکنر ضعیف، اندازهٔ ۶۰×۴۰ را انتخاب کنید.
- در سبک «ناوی» حتماً بارکد روی زمینهٔ سفید بماند (پیش‌فرض همین است) — اسکنر روی زمینهٔ تیره نمی‌خواند.
- برای چاپگر حرارتی: سبک «تک‌رنگ» + اندازهٔ دقیق رول + چگالی چاپ متوسط.
