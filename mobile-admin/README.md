# رابط کاربری اپلیکیشن اندروید پنل مدیریت

یک پروتوتایپ موبایل‌فرست و تعاملی برای پنل مدیریت فروشگاه سلیم‌وند است؛ با همان زبان بصری پنل دسکتاپ، اما با الگوی مناسب گوشی:

- راست‌چین کامل و متن‌های فارسی
- نوار پایین به‌جای سایدبار دسکتاپ
- دکمهٔ شناور برای صدور سریع فاکتور
- کارت‌های خلاصه به‌جای جدول‌های عریض
- فیلترهای قابل لمس برای انبار و محصولات
- شیت پایین برای صدور فاکتور، اعلان‌ها و پروفایل
- پوستهٔ روشن و تاریک بر پایهٔ توکن‌های سند UI پروژه
- جست‌وجوی سریع، فیلتر موجودی، تغییر تعداد کالا و پیام‌های موفقیت
- بدون کتابخانه یا asset خارجی؛ آیکون‌ها به‌صورت SVG داخلی هستند

## اجرا

فایل `index.html` را مستقیم در مرورگر باز کنید، یا از ریشهٔ ریپازیتوری اجرا کنید:

```bash
python3 -m http.server 4173
# سپس: http://localhost:4173/mobile-admin/
```

برای تست در اندازهٔ واقعی موبایل، viewport را روی یکی از اندازه‌های ۳۶۰ تا ۴۸۰ پیکسل بگذارید. در دسکتاپ، پوسته به‌شکل قاب موبایل نمایش داده می‌شود.

## نگاشت به اپلیکیشن اندروید

این فایل یک reference/prototype برای پیاده‌سازی Native یا Jetpack Compose است:

| بخش پروتوتایپ | معادل پیشنهادی اندروید |
|---|---|
| `.bottom-nav` | `NavigationBar` |
| `.fab` | `FloatingActionButton` |
| `.sheet` | `ModalBottomSheet` |
| `.summary-card` و `.kpi-card` | `Card` / `ElevatedCard` |
| `.inventory-item` و `.product-card` | `LazyColumn` item |
| توکن‌های رنگ در `styles.css` | `ColorScheme` روشن/تاریک |

> داده‌های داخل صفحهٔ نمونه هستند و به API متصل نیستند.
