# مفهوم رابط کاربری — فروشگاه سلیم‌وند

یک کانسپت بصریِ تک‌فایلی (بدون پیاده‌سازی بک‌اند) بر پایهٔ سند معماری پروژه.
برای دیدن، فایل `selimvand-ui.html` را در مرورگر باز کنید — کاملاً آفلاین کار می‌کند
(فونت وزیرمتن به‌صورت base64 جاسازی شده و هیچ منبع خارجی ندارد).

## چه چیزی داخل است؟

- **سایت عمومی** (کاتالوگ تک‌صفحه‌ای + نمای موبایل + فاکتور آنلاین `/invoice/[token]`)
- **پنل مدیریت** (ورود، داشبورد، صدور فاکتور + مودال موفقیت، فرم محصول تب‌دار،
  انبار + شیت اصلاح موجودی، لیست فاکتورها، گزارش سود، تنظیمات، جست‌وجوی سراسری Ctrl+K، نمای موبایل)
- **سیستم طراحی** (توکن‌های رنگ لایت/دارک، تایپوگرافی، فضا، دکمه/بج/فرم/جدول، حالت‌ها)

## کنترل‌ها

- دکمهٔ «دارک مود / لایت مود» در نوار بالا (و داخل موکاپ‌ها) — پوستهٔ هر دو محصول عوض می‌شود.
- چهار دایرهٔ رنگی در نوار بالا — چهار طیف پیشنهادی «آبی تیره» برای برند.
- تب‌های «سایت عمومی / پنل مدیریت / سیستم طراحی» برای جابه‌جایی بین نماها.
- کلیک روی هر سواچ رنگ در سیستم طراحی، هگز را کپی می‌کند.

## ساخت و بازسازی

```bash
python3 build.py          # خروجی: selimvand-ui.html
```

منابع سازنده: `icons.py` (آیکون‌ها و تصویرسازی قطعات)، `data.py` (دادهٔ نمونه)،
`screens_site.py` / `screens_admin.py` / `screens_ds.py` (نماها)،
`css_*.css` (استایل‌ها)، `fonts_b64.json` (فونت جاسازی‌شده).

## بررسی صحت

```bash
node verify.js   # ۲۳ تست تعاملی (پوسته، پالت، نماها، اجزا) — نیاز به jsdom
node shot2.js    # اسکرین‌شات نمای نزدیک — نیاز به playwright
```

اسکرین‌شات‌ها در پوشهٔ `shots/` موجودند.

> وضعیت: کانسپت طراحی — صرفاً برای ایده‌گرفتن، بدون اتصال به API.
